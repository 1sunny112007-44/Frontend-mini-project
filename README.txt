FLIPKART OFFLINE CLONE — MINI PROJECT
=====================================

Technologies:
- HTML
- CSS
- JavaScript
- Browser localStorage (to remember cart items on this device)

HOW TO RUN
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html.
4. The website opens in your browser. No server or database is needed.

FEATURES
- Flipkart-inspired homepage and navigation
- Product cards with category labels, prices and ratings
- Search products by name or category
- Filter products by category
- Sort by price or rating
- Add products to cart
- Increase/decrease quantity and remove products
- Cart total calculation
- Cart is saved in browser localStorage
- Demo checkout (no real payment)

IMPORTANT
- This is an educational frontend clone, not the official Flipkart website.
- Products are sample data written in script.js.
- No backend, online database, login, payment gateway or real order processing.
- Cart data is saved only in the browser on the same device.
- The layout and all core features work offline. The optional Google font in
  style.css may fall back to system fonts when there is no internet.

PROJECT FILES
index.html  -> page structure
style.css   -> design and responsive layout
script.js   -> product data and all interactions
README.txt  -> project instructions
